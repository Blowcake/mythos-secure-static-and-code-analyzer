# Release Notes - au3Mythos v1.2.1

We are pleased to announce the release of **au3Mythos v1.2.1**. This update hardens strict-mode (`-d -w 1..7`) block-scoping analysis for conditional `Local` declarations and direct left-hand-side assignments, refines multi-dimensional `IsArray` type guards, and adds exact compiled runtime line lookup (`--lookup-runtime-line <N> --compiled`).

## Highlights & Features

- **Strict-Mode LHS & Conditional `Local` Scoping Hardening**: Direct variable assignments without a declaration keyword (`$var = ...`, `$arr[$i] = ...`, `If ... Then $var = ...`) are now validated as scoping references against visible declaration scopes. Variables declared with `Local` inside one `If`/`ElseIf`/`Else`/`Select`/`Switch`/`Case` branch and assigned without `Local` in a sibling or subsequent block are immediately caught on the assignment line as `Block Scoping Bug`, `Reference Before Declaration`, or `Undeclared Variable`.
- **Visible-Scope Type Updates & Dimension-Agnostic `IsArray` Guard**: `record_scalar_assignment_type`, `type_check_rx` (`IsArray`/`IsObj`/`IsMap`), and `KNOWN_ARRAY_FUNCS` now update type information only within already visible declaration scopes rather than creating implicit fallback declarations. `IsArray($v)` registers dimension-agnostic array compatibility (`dims = None`), preventing false-positive `Array Dimension Mismatch` warnings on 2D arrays (such as `WinList()` or 2D SQLite result tables).
- **String-Aware Legacy Syntax Pass & Global/Static Write Handling**: `collect_legacy_syntax_errors` strips string literals before checking argument parentheses (preventing false-positive syntax aborts on expressions like `StringReplace($s, ")", "")`) and emits valid JSON diagnostics when `--json-out` is active. Writes to `Global` and `Static` variables inside functions are no longer reported as function-local `Dead Store` warnings.
- **Compiled Runtime Line Lookup (`--lookup-runtime-line <N> --compiled`)**: Strips `#include-once` directives, comment blocks (`#comments-start`/`#cs` .. `#comments-end`/`#ce`), comment lines, and blank lines identically to `Aut2Exe`, mapping compiled runtime crash line numbers directly back to the originating source file and line.

## Changelog Details

### Fixed
- Validated non-declaring LHS scalar and array-element assignments against visible declaration scopes (`scoping_references`).
- Prevented non-declaring assignments and `IsArray`/`IsObj`/`IsMap` guards from registering implicit function-scope variable declarations.
- Fixed false-positive `Array Dimension Mismatch` warnings when `IsArray($v)` guards a 2D array.
- Fixed `collect_legacy_syntax_errors` misinterpreting closing parentheses inside string literals and added structured JSON output in `--json-out` mode.
- Excluded `Global` and `Static` variables from function-local `Dead Store` warnings.
- Propagated `-compiled` / `--compiled` in `Au3Check_Wrapper.au3` and preserved explicit CLI `-w` flags over GUI defaults.
- Updated `Setup_au3Mythos_x64.au3` and `Uninstall_au3Mythos_x64.au3` to automatically update the active `AutoIt3\Au3Check.exe` wrapper during in-place upgrades (when `Au3Check_Original.exe` is present), remove legacy `Uninstall.exe` binaries, and bundle all documentation (`au3Mythos_JSON_API.md`) and splash/icon assets (`resources\`).
- Fixed conditional `Local` variable reuse in `au3Mythos_Settings.au3` (`LoadConfig`) and preserved `@error` across handle cleanup in `Au3Check_Wrapper.au3`.

### Tests
- Added regression fixtures in `tests/test_warning_fixtures.py` for conditional `Local` declarations followed by sibling-branch assignments without `Local` and string literals containing `)` in strict mode.
- Added wrapper E2E test coverage in `tests/test_wrapper_e2e.py` for `-lookup_runtime_line -compiled`.
