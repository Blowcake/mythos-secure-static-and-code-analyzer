# Release Notes - au3Mythos v1.2.2

We are pleased to announce the release of **au3Mythos v1.2.2**. This release eliminates false positives discovered during large-scale multi-project and community UDF audits while preserving full strict-mode (`-d -w 1..7`) sensitivity for genuine runtime and scoping bugs.

## Highlights & Features

- **1D `UBound($arr) > 0` Bounds Guard (including `ElseIf` branches)**: Accessing `$arr[0]` on zero-initialized arrays (`Global $g_aDirs[0]`, `Local $aEmpty[0]`) no longer triggers a false-positive `Array Subscript Out of Bounds` warning when guarded by `UBound($arr) > 0`, `UBound($arr, 1) >= 1`, or `UBound($arr) <> 0` in `If` or `ElseIf` conditions.
- **Infallible Local Map & Array Helper Inference (`infallible_map_funcs`, `infallible_array_funcs`, `infallible_array_dims`)**: A fixed-point pre-pass across the script and its include tree identifies helper UDFs (independent of declaration order, including transitive delegation) that return a locally declared Map (`Local $m[]`) or dimensioned Array (`Local $a[...]`, preserving 1D/2D/3D rank and rejecting variables overwritten as scalars) on every `Return` path without `SetError`.
- **Built-in Array Returns & Argument-Safe `MapExists` Guard**: Adds `WinList` (2D) and `_PathSplit` (1D) to `KNOWN_ARRAY_FUNCS` / `KNOWN_ARRAY_DIMS`, and treats `MapExists($m, ...)` / `_MapExists($m, ...)` as a Map type guard for `$m` without masking unchecked dereferences inside the second (key) argument.
- **Array Dimension Expression Reads (`-w 5` Unused Variable)**: Variables referenced inside local array declaration brackets (e.g. `Local $iCount = ...` followed by `Local $aTools[$iCount]`) are now recorded as read references alongside `ReDim`.
- **Same-Line RHS Self-Assignment Dereference Precision**: Self-assignments such as `$oItem = _OL_ItemMove($oOL, $oItem, $oItem.Parent.StoreID, $vFolder)` no longer misclassify the pre-call argument evaluation `$oItem.Parent.StoreID` on the assignment line (`ln`) as an unguarded post-call return dereference, while still flagging unguarded dereferences on subsequent lines.

## Changelog Details

### Fixed
- Propagated `ElseIf` guard conditions on the active `If` stack and exempted `UBound($arr) > 0`-guarded index `0` accesses on `0`-sized arrays from `Array Subscript Out of Bounds`.
- Added fixed-point pre-pass inference for infallible Map- and Array-returning helper UDFs (including multi-dimensional array rank preservation and scalar-reassignment rejection).
- Added `WinList` (2D) and `_PathSplit` (1D) to `KNOWN_ARRAY_FUNCS` / `KNOWN_ARRAY_DIMS`.
- Recognized `MapExists` / `_MapExists` as a Map type check without stripping the key expression from dereference scanning.
- Recorded variable references inside local array dimension brackets (`Local $a[$n]`) as read accesses.
- Excluded same-line RHS argument evaluations on self-assignments (`$v = _Func($v.Prop)`) from false-positive `Unsafe Return Dereference` / `Unsafe Object Dereference` warnings.
- Preserved byte-exact line endings when backing up and restoring `resources/mythos_config/config.json` in `tests/test_wrapper_e2e.py`.

### Tests
- Added positive and negative regression coverage in `tests/test_warning_fixtures.py` (`test_ubound_guard_infallible_helpers_and_array_dim_reference_no_false_positives`) covering `ElseIf UBound($arr) > 0`, 1D/2D infallible helpers (including forward delegation and scalar-reassigned counterexamples), `WinList()`, `MapExists` key dereferences, local array dimension reads, and same-line RHS self-assignments.
